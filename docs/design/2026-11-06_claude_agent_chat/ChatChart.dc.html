run_id = down.ne(down.shift()).cumsum()
for _, run in weekly[down].groupby(run_id[down]):
    loss = run.iloc[-1] / weekly.shift(1)[run.index[0]] - 1
    if len(run) >= 5 and loss <= -0.30:

前 4 次都发生在系统性冲击里：2002 年的泡沫破裂、2008 年的金融危机、2020 年的疫情。2002 年那一轮还在 5–6 月之后又跌出了第二段（02），说明这种程度的下跌不一定是一次性出清。

要判断这次像哪一次，关键是看有没有同级别的宏观冲击。如果没有，更可能是行业自身的估值或库存周期在调整，节奏和前 4 次会不一样。样本只有 4 个，不能当成规律直接套用。
