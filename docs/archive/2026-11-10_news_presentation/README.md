# 新闻讲解、工具详情与来源分组验收

已部署版本：`agent-20261110-7c00e5d7b749`。本次代码未提交 Git，主目录原有改动保留。

## 行为

- 能力验证命中有效缓存时直接进入研究；冷检查、成功和失败都有实际状态说明。缓存仍按模型、端点、凭据与推理配置隔离，并保持原有一小时有效期。
- 工具详情采用纵向布局，长结果独占可用宽度。新闻结果展示文章标题、来源、日期和摘要；读取资料的界面投影展示资料摘要与读取范围，模型收到的原始片段不改变。引用标识按需展开。
- 普通新闻问句使用中文解释事件、相关性和可能影响。局部核验失败保留其他有效段落，不将整段解释换成英文原文列表；只有明确只要标题/链接时才允许原文索引兜底。
- 文章标题链接保持可读文字；数字引用保持编号和侧栏跳转。原始 headline 不再被媒体名称覆盖。
- 回答下方来源按媒体/供应商分组，整体及各组默认折叠，可独立展开；保留每条证据原编号和原文地址。
