## 侧栏展示对照

| 改前 | 改后 |
|---|---|
| 最近对话为静态标题 | 折叠按钮，带 chevron 和 `aria-expanded`，默认展开 |
| 不记住折叠状态 | `finsight.sidebar.recentCollapsed` 保存整体状态，刷新后保留 |
| 全部会话逐组展示 | 先按原分组顺序取前 8 条，超过后显示“查看全部 {N} 条 →” |
| 分组始终展开 | 今天、昨天默认展开；7天内、更早默认收起 |
| 组标题无计数 | 组标题右侧显示完整组条数，点击切换折叠 |
| 标题显示末尾日期括号 | 只清洗展示标题；`title` 属性保留完整原文 |
| 同名标题难以区分 | 在完整分组中判断重名，右侧显示 HH:mm 或 MM/DD |
| 列表没有截断补位需求 | 当前选中项若被截断或藏在收起的组里，追加末尾并高亮，不重复 |

`conversation-rail`、`conversation-item`、`conversation-delete`、删除流程及 compactMobile 行为均保留。全部历史入口调用现有 `onHistoryClick`。原始标题、排序、会话记录不改。
