## 方法
先取得价格、已披露财务数据和盈利预期，标明时点、财期、币种与估值分母。历史事实、市场一致预期与用户假设分开记录；市盈率、企业价值倍数和现金流估值不可混用分母。

需要计算或情景比较时用 run_python，假设保留为输入数据并记录 method；成组数字用 render_table，敏感性用 render_chart。竞争公司只承担用户要求的比较或背景范围，不自行扩大主体。

资料缺失时说明哪些结论无法核实。模型自报判断不等同于统计概率，不把单一估值倍数直接当作买卖指令。
