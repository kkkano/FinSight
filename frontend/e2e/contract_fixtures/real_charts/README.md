# 真实图表冻结契约数据

本目录供 `real-chart-artifacts.spec.ts` 在本地与 CI 重放 2026-11-07 已生成的模型图表产物，不代表测试执行时的实时行情或新的模型输出。

- 六份 `chart_*.json` 按原始字节复制，所有行、数值、面板、方法、限制与引用保持完整。
- 三份 `datasets.json` 按原始字节复制，保留原始记录与来源，用于独立核验 MA20 和 NVDA/AMD 交叉日期。
- 三份 `sources.json` 仅投影原 `terminal.json` 的完整 `evidence_pool`，保留每条记录及全部字段；不携带不参与图表测试的回答正文和运行会话身份。
- `manifest.json` 记录本机原件的仓库相对路径、原件 SHA-256、复制/投影后的 SHA-256 和 source/dataset/input 引用绑定。原件未修改。

复制前检查了非空凭据/账号/会话身份字段与常见 token 格式；测试以假认证运行，阻断全部非 localhost 浏览器网络，不启动研究执行。测试核验原图和来源文件 SHA、渲染数值与原始数值一致，并保留原有点数、交叉日期、均值与来源断言。
